용어는 [GLOSSARY.md](../GLOSSARY.md)를 따른다. 수치는 Colab T4 실행 결과(`outputs/results/`)이고, 노트북은 [01](../notebooks/01_nsmc_polarity_executed.ipynb) · [02](../notebooks/02_kote_eda_mapping.ipynb) · [03](../notebooks/03_direct_vs_two_stage.ipynb) · [04](../notebooks/04_final_model.ipynb)이다. 발표 자료: [results.pptx](results.pptx) ([PDF](results.pdf)).

## 한눈에 보기

| | 결과 |
|---|---|
| Before: NSMC 극성 분류 재현 | test 정확도 **91.09%** (KoELECTRA 보고치 90.63%) |
| 직접 학습 (KOTE 8범주) | test macro F1 **0.6734 ± 0.0032** |
| 2단계 학습 (NSMC → KOTE) | test macro F1 0.6656 ± 0.0076 |
| 최종 모델 (2단계 학습 seed 44) | test macro F1 0.6668 → **0.6756** (범주별 threshold 튜닝) |
| NSMC 극성 일관성 | 긍정 리뷰 82.5%에 기쁨, 부정 리뷰 88.9%에 부정 계열 감정 |

- 극성 분류(긍정/부정)를 8개 감정 범주의 다중 라벨 감정 분류로 확장했다.
- NSMC를 먼저 거치는 2단계 학습은 직접 학습보다 **나아지지 않았다**. 차이(0.008)는 시드 간 표준편차 수준이다.
- 최종 모델은 범주별 threshold 튜닝으로 직접 학습 평균과 비슷한 수준까지 올라왔다.

## 1. 무엇을 바꿨나

| 바뀐 지점 | Before (극성 분류) | After (감정 분류) |
|---|---|---|
| 출력 수 | 2 (부정, 긍정) | 8 (기쁨·슬픔·분노·공포·놀람·혐오·지루함·중립) |
| 활성화·손실 | softmax + cross-entropy | sigmoid + BCE (범주마다 따로 판단) |
| 정답 형태 | 정수 0/1 | 8칸 0/1 벡터 |
| 학습 순서 | 사전학습 → NSMC | 사전학습 → NSMC → KOTE (2단계 학습) |
| 출력 규칙 | — | 배타 규칙: 다른 범주가 켜지면 중립을 끈다 |

- 모델: `monologg/koelectra-base-v3-discriminator` (ELECTRA 판별기 인코더 + 분류 헤드)
- 감정 데이터: KOTE 44개 원본 라벨 → 대응표로 8개 감정 범주, 평가자 5명 중 2명 이상 기준. train / val / test = 38,687 / 4,835 / 4,844
- 공통 설정: 3 epoch, lr 5e-5, batch 64, max_len 128, 시드 42/43/44, epoch마다 val macro F1로 가장 좋은 epoch 선택(모든 실행에서 3 epoch이 최고)

## 2. 직접 학습 vs 2단계 학습 (03)

두 방식은 같은 시드에서 헤드 초기값이 같고, **인코더 가중치만 다르다**.

| 방식 | 시드 | val macro F1 | test macro F1 |
|---|---|---|---|
| 직접 학습 | 42 | 0.6648 | 0.6731 |
| 직접 학습 | 43 | 0.6703 | 0.6767 |
| 직접 학습 | 44 | 0.6658 | 0.6704 |
| 2단계 학습 | 42 | 0.6514 | 0.6574 |
| 2단계 학습 | 43 | 0.6669 | 0.6726 |
| 2단계 학습 | 44 | 0.6688 | 0.6668 |

| | val macro F1 | test macro F1 | test micro F1 |
|---|---|---|---|
| 직접 학습 | 0.6670 ± 0.0029 | **0.6734 ± 0.0032** | 0.7422 ± 0.0009 |
| 2단계 학습 | 0.6624 ± 0.0096 | 0.6656 ± 0.0076 | 0.7392 ± 0.0035 |

범주별 test F1 (시드 평균):

| 감정 범주 | 직접 학습 | 2단계 학습 | 차이 |
|---|---|---|---|
| 기쁨 | 0.862 | 0.862 | +0.001 |
| 슬픔 | 0.723 | 0.720 | −0.003 |
| 분노 | 0.843 | 0.843 | +0.000 |
| 공포 | 0.464 | 0.443 | −0.021 |
| 놀람 | 0.616 | 0.605 | −0.011 |
| 혐오 | 0.677 | 0.670 | −0.007 |
| 지루함 | 0.727 | **0.752** | **+0.025** |
| 중립 | 0.476 | 0.430 | **−0.046** |

- 2단계 학습은 **지루함에서만** 확실히 나았고, **중립·공포·놀람**에서 손해를 봤다.
- 2단계 학습은 시드 간 편차도 더 컸다 (seed 42가 특히 낮음).
- 해석(가설): NSMC 극성 학습은 리뷰를 긍정/부정 축으로 정리한다. 그래서 영화 도메인의 대표적 부정 감정인 지루함("노잼")은 도움을 받았다. 반대로 극성과 무관한 중립·공포·놀람은 그 축에 묻혔다.

## 3. 최종 모델 (04)

- **최종 모델 = 2단계 학습 seed 44**
  - 2단계 학습 3시드 중 val macro F1이 가장 높았다 (0.6688).
  - 최종 모델은 비교 결과와 관계없이 2단계 학습으로 미리 정해 두었다 (GLOSSARY).
  - 선택에는 test를 쓰지 않았다.

### 범주별 threshold 튜닝

val에서 범주마다 F1이 가장 높은 threshold를 0.05~0.95 범위에서 골랐다.

| 기쁨 | 슬픔 | 분노 | 공포 | 놀람 | 혐오 | 지루함 | 중립 |
|---|---|---|---|---|---|---|---|
| 0.40 | 0.40 | 0.45 | 0.30 | 0.30 | 0.25 | 0.55 | 0.30 |

| test | 기본 (0.5) | threshold 튜닝 |
|---|---|---|
| macro F1 | 0.6668 | **0.6756** |
| micro F1 | 0.7421 | 0.7429 |
| 판정 없음 비율 | 3.5% | 0.7% |
| 배타 규칙 위반 (규칙 적용 전) | 4건 | 43건 |

| 감정 범주 (test F1) | 0.5 | 튜닝 | 차이 |
|---|---|---|---|
| 기쁨 | 0.867 | 0.865 | −0.003 |
| 슬픔 | 0.719 | 0.724 | +0.005 |
| 분노 | 0.844 | 0.849 | +0.005 |
| 공포 | 0.456 | 0.483 | **+0.027** |
| 놀람 | 0.611 | 0.639 | **+0.028** |
| 혐오 | 0.676 | 0.689 | +0.013 |
| 지루함 | 0.765 | 0.764 | −0.001 |
| 중립 | 0.396 | 0.393 | −0.003 |

- 튜닝으로 소수 범주 중 **공포·놀람·혐오**가 올랐다.
- **중립은 나아지지 않았다.**
  - 중립 threshold를 0.3으로 낮추자, 다른 범주와 함께 켜지는 배타 규칙 위반이 4건에서 43건으로 늘었다.
  - 규칙이 그 중립을 끄면서 튜닝 효과가 사라졌다 (val 중립 F1은 0.453 → 0.402로 오히려 하락).
  - 범주별 독립 튜닝과 배타 규칙이 서로 맞지 않는 지점이다.
- 지루함은 0.5에서 이미 F1 0.76이라 튜닝 효과가 없었다.

## 4. NSMC 리뷰 데모

최종 모델 + 튜닝 threshold로 예측했다 (확률). 판정 없음이면 확률이 가장 높은 범주를 "(약함)"으로 표시한다. 이 표시는 데모 출력에만 쓰고, 지표에는 쓰지 않는다.

| 리뷰 | NSMC 극성 | 예측 감정 범주 |
|---|---|---|
| 배우들 연기가 미쳤다. 두 번 봐도 또 보고 싶음 | 긍정 | 기쁨 1.00, 놀람 0.64 |
| 시간 아깝다 진짜 노잼 | 부정 | 슬픔 0.94, 분노 0.97, 혐오 0.35, 지루함 0.96 |
| 결말이 너무 어이없어서 화가 난다 | 부정 | 슬픔 0.95, 분노 0.99, 놀람 0.46, 혐오 0.31, 지루함 0.67 |
| 마지막 장면에서 펑펑 울었다 | 긍정 | 기쁨 0.88, 슬픔 0.83 |
| 중간에 깜짝 놀라서 소리 질렀음 | 긍정 | 놀람 0.95 |
| 연출은 좋은데 너무 길어서 졸렸다 | — | 슬픔 0.96, 분노 0.93, 지루함 0.89 |
| 사랑한다는 말을 하지않아도... | 긍정 | 기쁨 0.25 (약함) |

- "별로다" 계열의 부정 리뷰가 **지루함**(노잼, 길어서 졸림)과 **분노**(어이없음)로 구분된다. 이것이 프로젝트의 동기였다.
- 부정 리뷰에는 슬픔과 분노가 함께 켜지는 경우가 많다. 대응표에서 "안타까움/실망"은 슬픔으로, "불평/불만"은 분노로 묶었기 때문으로 보인다.

## 5. NSMC 극성 일관성 (극성별 2,000건)

| NSMC 극성 | 기쁨 켜짐 | 분노·슬픔·혐오·지루함 중 하나 | 둘 다 | 판정 없음 |
|---|---|---|---|---|
| 긍정 | **82.5%** | 23.1% | 10.0% | 1.0% |
| 부정 | 8.3% | **88.9%** | 2.0% | 0.8% |

- KOTE 댓글로만 감정을 배웠는데도, 영화 리뷰의 극성과 감정 범주가 대체로 맞물린다.
- 어긋난 리뷰는 4,000건 중 387건(9.7%)이다. 예를 들면 다음과 같다.
  - "ㅋㅋㅋㅋ아웃겨죽겟네 ㅋㅋ"(NSMC 부정 → 기쁨): NSMC 라벨 쪽 잡음으로 보인다.
  - "평점 왜이렇게 안좋지;; 개인적으로 엄청 재미있게 봤거든요"(NSMC 긍정 → 슬픔·분노): 평점에 대한 불만을 감정으로 읽었다.

## 6. 한계

- 시드가 3개라 통계 검정을 하지 않았다. 2단계 학습 3시드는 모두 같은 NSMC 모델(seed 42)에서 출발해서, NSMC 학습의 변동은 표준편차에 들어 있지 않다.
- 중립 threshold는 val 약 150건으로 정해져 불안정하다.
- KOTE 라벨에는 잡음이 있고, 영화 리뷰는 KOTE 12개 출처 중 하나뿐이다. NSMC 데모와 일관성 점검은 도메인이 다른 데이터에 대한 정성 평가다.
- 원인 설명(극성 학습이 극성과 무관한 감정을 흐림, 대응표 때문에 슬픔·분노가 동시에 켜짐)은 수치에서 세운 가설이고, 따로 검증하지 않았다.

## 7. 향후 과제

- 중립을 다른 범주와 함께 튜닝하거나(배타 규칙을 반영한 threshold 탐색), 중립 전용 판정 규칙 도입
- `pos_weight` 등 불균형 보정 (이번에는 하지 않음)
- NSMC 학습 시드도 바꿔 2단계 학습의 변동 측정
- 영화 리뷰에 직접 감정 라벨을 붙인 평가셋 구축
